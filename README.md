# Product Inventory Management System
CRUD web app built with HTML, CSS, JavaScript, PHP, MySQLi and MySQL.

## Files
- `database.sql` – table + sample data
- `db.php` – MySQLi connection
- `index.php` – Read (list + search)
- `add.php` – Create
- `edit.php` – Update
- `delete.php` – Delete
- `style.css` – design

## Run locally (XAMPP)
1. Copy folder to `htdocs`, create database `inventory_db`, import `database.sql`.
2. Open http://localhost/inventory/
